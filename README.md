# 对流增雨装置数值试验 · 代码包

一个 r–z 二维轴对称大气求解器，用来回答一个问题：地面上一台直径 300 米、轴功率 126 MW 的水平旋翼风机，能不能把近地面的湿空气送过自由对流高度，触发对流并产生降水。

代码包含完整的动力学求解器、六类水物质微物理、致动盘风机强迫、稳定步长扫描，以及三个自校验脚本。所有结果都可以从零重跑，不依赖任何外部数据文件。

## 2. 先跑自校验（约 2 分钟）

```bash
python verify_factors.py          # 六个物理开关的守恒 / 量级 / 方向
python verify_rim_kinematics.py   # 淞附相对速度与上升气流无关（双支路）
```

两条都应打印 `全部 PASS`。`verify_factors.py` 里有一项需要历史快照 `long_rain0_final.npz`，没跑过时会自动跳过，不影响其余判定。

校验脚本的作用是确认微物理实现与手算一致、水量守恒、散度干净。它们保证的是"代码没写错"，不构成对真实大气的验证。

## 3. 跑一个完整算例

```bash
python run_long.py k1a2 1.0
```

`k1a2` 是本包的主算例：华北平原夏季闷热中午的探空、夹卷 `ke=0.01`、淞附与质量依赖落速开启，从 t=0 连续积分 60 分钟。

| 项 | 值 |
|---|---|
| 计算域 | 水平半径 12 km，垂直 16 km |
| 网格 | 332 × 347 = 115 204 |
| 近场分辩率 | 4.0 m（r < 650 m、z < 600 m） |
| 时间步 | 0.011–0.060 s，自适应 |
| 墙钟 | 单进程约 8.5 小时 |

输出两个文件：

- `long_k1a2.log`：每 2 分钟一行诊断，列为
  `t(min) dt 云顶 雨强max 雨强均值 雨覆盖km² qc_max qr_max qg_max 地面LWC 能见度 雾区km²`
- `long_k1a2_00300.npz` … `long_k1a2_final.npz`：每 5 分钟一个全场快照，可直接续跑

续跑到两小时：

```bash
python run_long.py k1a2b 1.0
```

`k1a2b` 的初值就是 `k1a2` 的末态，开关完全一致。

## 6. 物理设定要点

**动力学。** anelastic 方程组，有限体积离散，对流项 QUICK，扩散项中心差分。压力用变量系数泊松方程求解，每步做一次投影保证离散散度为零。

**时间步。** 每步扫描全域所有波数的增长率，取 `dt_crit(θ) = −2Reλ/‖λ‖²` 的最小值，再乘 0.75 的安全裕量。比按 CFL 和 Fourier 数拼接的经验判据严格，代价是步长更小。

**边界。** 底面不可入，轴线对称，侧面与顶面开口。出流边界的法向速度由离散连续方程反解得到，不是零梯度外推——外推会让角落单元的垂直散度算成零，出流偏差约 2%。

**微物理。** 六类水物质 bulk：水汽、云水、冰晶、雨、雪、霰。含 Kessler 自动转化、云水碰并、云水冻结、冰晶转雪、淞附、霰的干增长与融化、雨水蒸发。水凝物负载已经含在虚位温里（`θv = θ(1 + 0.608qv − qc − qi − qr − qs − qg)`），不再单加拖曳项，两者重复计入会把降水量虚增 2.4 倍。

**夹卷。** `ε = ke / max(R_eff, 75 m)`，`R_eff` 是凝结物的质量加权半径，`ke = 0.01`，对应 `ε ≤ 0.13 /km`。分母必须设下限：云刚形成时 `R_eff` 只有 1–5 米，不设下限会把 `ε` 放大两个量级，对流被瞬间稀释掉。

**风机。** 致动盘模型，半径 150 m、轮毂 15 m、盘高 140 m、旋流比 0.15、目标轴向速度 17 m/s，叶尖损失按外侧 10% 平滑衰减。机械功由 `∫ρa·w dV` 在流场上直接积分得到，不按流量乘速度头反推。

## 7. 已知限制

这套模型能回答"装置能不能触发对流、云长什么样、雨落在多大范围"，不能回答工程产水量的绝对值。原因是：

- **轴对称。** 不含方位向扰动、涡对、环境风与切变。真实大气的羽流会被吹斜，落区会偏移。
- **单次实现。** 没有集合，同配置下 8 分钟状态的本底敏感度实测 1–3%。
- **微物理参数未标定。** 粒子数浓度、收集系数、粒子密度都按文献量级取值，误差因子 2–5 倍。
- **固定粒径谱。** 单参数 bulk，不能描述聚并、破碎对谱宽的影响。
- **网格未收敛。** 只有 4 m 与 2 m 两个分辨率的结果，缺 1 m 点。

产水量按"数千立方米每场"看待是稳的，精确到个位数不成立。
